# Sayway — Say it your way

**Meaning first. Expression second.**

Sayway 是一款 **AI 英语表达伴侣（AI English Expression Companion）**：把你模糊的想法、中文表达和不完整的英语意图，转化为自然、符合语境、保留个人风格的英文表达。

> 注：它不是单纯的翻译软件。它和普通翻译器最大的区别是——**允许你输入非常不完整的表达**。

---

## 适合谁

- 词汇量不多、英语表达习惯较为局限的人；
- 想脱口而出电影台词、却卡在专有名词和定语的人；
- 心里有个形容、翻遍书查无此词的人；
- 追求地道、俚语，甚至想制造双关、幽默、调皮表达的人。

> 如果你常常觉得「用母语时我很幽默，换英语就干巴巴了」——Sayway 想帮你说出那个更接近你的版本。

## 和普通翻译器最大的区别

你可以直接输入这些：

- 表面上说没关系，实际上很介意。
- 想表达有点厌世，但是又不是抑郁。
- 想说得有点阴阳怪气，但不刻薄。

Sayway 会先理解你的意思，再给你符合英语习惯、语境和情绪的表达。

## 已实现的功能

- **表达转换（Translate）**：中英及混合输入自动识别；选择表达方向（自然/可爱/调情/幽默/双关/地道/礼貌/商务…），得到多个语义保真的英文版本，含中文回译、语气说明与解释。
- **场景对话（Chat）**：自由对话与情景练习，可选难度与纠错强度，边聊边纠语法。
- **场景口译（Interpreter）**：中英双向场景口译（餐厅/医院/交通/租房等 13 个场景），轮流说话自动翻译并朗读，支持拍照识别菜单与告示。
- **学习（Learn）**：单词探索（单击释义、双击详情、按词性分组）、影子跟读与逐词练习、写作纠错、每日阅读。
- **本地优先**：历史、收藏、学习记录保存在本地浏览器，不强制注册、不绑定手机号。

## 隐私与数据

- 无需注册、不绑定手机号或邮箱。
- 你的学习记录默认保存在自己的浏览器（IndexedDB）。
- 仅在你主动发起 AI 请求时，必要文本才发送到后端；后端不保存完整聊天或翻译内容。
- 内测阶段为邀请制，管理员只统计匿名行为数据（用量/功能），不采集原始输入。

## 技术概览

- 前端：React + TypeScript + Vite + Tailwind CSS
- 后端：Node.js + Express
- 本地数据：IndexedDB
- AI：SiliconFlow（deepseek-ai/DeepSeek-V3.2）
- 语音：浏览器原生 TTS / STT
